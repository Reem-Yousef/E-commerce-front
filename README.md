# E-Commerce Web Application

A full-stack e-commerce application built with **Angular, Node.js, Express.js, and MongoDB**, providing a complete shopping experience with product discovery, filtering, reviews, cart management, and checkout.

Backend Repository: [View Backend Code](https://github.com/Reem-Yousef/E-commerce-back)

## ✨ Features

- **Product Browsing:** Explore the available products.
- **Search & Filtering:** Find products using search and filtering functionality.
- **Product Reviews:** Support for customer product reviews.
- **Shopping Cart:** Manage selected products before checkout.
- **Checkout:** Proceed through the checkout process.
- **User Sessions:** Backend support for managing user sessions.
- **Order Management:** Handle orders through the backend.
- **Database Integration:** Store and manage products, users, and orders using MongoDB.

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js

## 🏗️ Architecture

The application follows a full-stack architecture:

- **Angular frontend:** Provides the user interface and shopping experience.
- **Node.js and Express.js backend:** Handles application logic, API requests, user sessions, products, and orders.
- **MongoDB:** Stores application data, including products and orders.
